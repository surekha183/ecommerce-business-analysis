# E-commerce Delivery Delay Root-Cause Analysis & AI Copilot

## Project Overview
An e-commerce analytics project using the Olist Brazilian E-Commerce Public Dataset to analyze delivery delays, customer reviews, and delivery performance.

## Objectives
- Identify late delivery patterns.
- Analyze delivery performance across states and sellers.
- Compare customer review scores for late and on-time deliveries.
- Present actionable insights through SQL, Python, and Power BI.

## Tech Stack
- Python and Pandas
- PostgreSQL and SQL
- Power BI and DAX
- Git and GitHub

## Project Structure
- `data/` — Dataset source and data documentation
- `notebooks/` — Data cleaning and exploration
- `sql/` — SQL analysis and views
- `powerbi/` — Power BI dashboard
- `screenshots/` — Dashboard images

## Dataset
Olist Brazilian E-Commerce Public Dataset, available on Kaggle:  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The raw dataset is not included in this repository. Download it from the source and follow the project instructions to reproduce the analysis.

## Key Analysis
- Eligible delivered orders and late delivery rates
- Delivery-stage durations
- State-level delivery performance
- Customer review scores by delivery outcome
